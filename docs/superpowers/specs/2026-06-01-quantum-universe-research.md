- **Q1 — Qubit hardware / quantum computers** (the pure-plays + big-cap programs), by modality.
- **Q2 — Cloud / QaaS / full-stack platforms** (hyperscaler clouds + native clouds + services primes).
- **Q3 — Software / algorithms / error-correction / middleware.**
- **Q4 — Networking & post-quantum security** (QKD, quantum networking, PQC, QRNG).
- **Q5 — Applications / demand-side** (pharma, finance, auto, aerospace — customers, not quantum businesses).
