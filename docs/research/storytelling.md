# Storytelling — Structures & Hooks (2025-26)

Grounded for **@valuewithvalues**: flat-2D animated, deadpan finance sketch, ~15-20s, captioned, optional TTS VO + newsroom bed. Every structure below assumes that format — cold open on the visual/number, no throat-clearing, one payoff per video.

---

## Decision guide — pick a structure by goal

| Goal | Structure | Length | Why it fits |
|---|---|---|---|
| Single sharp insight, max reach | **Myth-Bust / Contrarian Flip** | 15-20s | Perspective-shift hook interrupts scroll in 1-3s; matches our single-scene sketch format |
| Explain a mechanism (why a stock moved, how a multiple works) | **Question → Math → Reveal** | 20-34s | Question-hooks test highest for explainer content; gives the deadpan narrator room for 2 beats |
| Dense/technical (DCF, valuation, multi-part fundamentals) | **Episodic Cliffhanger (Part 1/2)** | 2x15-20s | Platform pushes ep. 2 to ep. 1 viewers; splits comprehension load without cutting content |
| Build a recurring character/audience habit | **Journey/Series Beat** ("Day 47 of...") | 15-20s per ep. | Session depth + follow-for-next; works well with a recurring newsroom-anchor character |
| Compliance-sensitive concept explainer | **Practitioner Plain-Language** | 20-30s | Explains mechanics not trades; safest posture, still authoritative in deadpan VO |
| Quick reactive take on news/earnings | **Identity-Call Reaction** | 15-20s | "If you own X..." filters for invested viewers, fast to produce same-day |

---

## Hook formulas (first 1-3 seconds — write these as literal on-screen text + VO line 1)

Use these directly as scene-1 captions/VO for the sketch's opening frame.

1. **Identity Call** — "If you [own / bought / are still holding] {TICKER} [condition]..."
   - Example: "If you bought Palantir under $20, watch this before Friday."
2. **Front-Loaded Payoff** — state the number/result first, explain second.
   - Example: "This stock is 40% overvalued — here's the math."
3. **Why/How Question** (best for explainer format specifically)
   - Example: "Why did this AI chip stock drop 12% on good earnings?"
4. **Myth-Bust / Contrarian Flip** — name the assumption, then flip it.
   - Example: "Nobody told you this about your 401k fee."
5. **Cost-Framed Number** — a dollar loss stated cold, no lead-in.
   - Example: "$4,200 mistake." (jump-cut/zoom-punch on word one)

**Rule of thumb for our sketch:** open on frame 1 with the deadpan character already mid-scene (not walking in, not intro'd) and the hook line as the FIRST spoken word + simultaneous caption pop. No logo sting before it.

## Beat-by-beat: Myth-Bust / Contrarian Flip (our default 15-20s structure)

| Beat | Time | Content |
|---|---|---|
| Hook | 0-2s | Contrarian claim, cold open, caption pops with VO word 1 |
| Setup | 2-6s | One sentence of context — what people assume |
| Turn | 6-12s | The flip / the math / the reveal — this is the payoff, front-loaded as visual (chart, number slam) |
| Button | 12-18s | Deadpan one-liner landing the joke/insight; visual mirrors frame 1 for loop |
| CTA | 18-20s | One earned CTA (see scripting.md) |

## VIRAL vs DEAD table

| Pattern | Verdict | Why |
|---|---|---|
| Identity-call hook ("if you own X...") | VIRAL | Specificity beats reach; filters for invested viewer |
| Front-loaded payoff (number/result in frame 1) | VIRAL | Sets ceiling for entire retention curve |
| Why/how question hook for explainers | VIRAL | Highest avg-view hook type for educational format |
| Episodic Part 1/2 cliffhanger | VIRAL | Platform actively recommends ep. 2 to ep. 1 viewers |
| Mirrored first/last frame (loop bait) | VIRAL | Rewatch rate now outranks follower count as distribution signal |
| Mid-video re-hook at 20-30s | VIRAL (for videos >20s) | Prevents natural drop-off past the opening hook's shelf life |
| Generic "POV: you just discovered X" | DEAD | 2023 format, no longer earns hook slot without a sharp specific frame |
| Generic rhetorical question ("Did you know...?") | DEAD | Undifferentiated, underperforms specificity/identity hooks |
| Slow scene-setting lead-in / logo intro / "hey guys" | DEAD | Burns the <3s window before drop-off; costs the whole video |
| Over-polished "ad-like" open | DEAD | Trips skepticism filters, especially in finance (authenticity signals trust) |
| Single hook, no loop/re-hook plan | DEAD | Caps below 20-30% rewatch benchmark that now matters more than followers |
| Subway Surfers / brainrot split-screen under finance VO | DEAD | Mismatched with trust-building goal, reads as gimmicky, hurts retention/comprehension |
| Generic "day in the life of a trader" flex content | DEAD | Oversaturated, near-identical beats, low differentiation |

## Applying to our sketch format specifically

- **Frame 1 = thumbnail.** The deadpan character + one bold on-screen number, high contrast, before any camera move. This is true even though it's animated — the first frame is what the feed shows pre-tap.
- **Loop the sketch.** End on the same static pose/expression as the open (or a resolved sight-gag that only lands on a second viewing) — this is cheap to build into a flat-2D animation since backgrounds/poses are already modular assets.
- **Episodic split for dense material.** A full valuation walkthrough becomes "Part 1: the number everyone's misreading" / "Part 2: the actual math" — reuses the same character rig and set, just a second script.
- **Identity-call hooks pair naturally with our ticker-specific format** (e.g. AMD calls, Palantir, quarterly earnings reactions) — literally name the ticker + condition in VO line 1.
