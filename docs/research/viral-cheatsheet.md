# Viral Cheatsheet — One Page (2025-26)

For **@valuewithvalues**: flat-2D animated deadpan finance sketch, ~15-20s, captioned, optional TTS VO + newsroom bed. Distilled from storytelling.md, scripting.md, voiceover-audio.md — use this as the pre-publish checklist.

---

## The single-page VIRAL vs NOT table

| Element | VIRAL (do) | NOT (avoid) |
|---|---|---|
| **Opening 0-2s** | Cold open on claim/number/chart, hook line = VO word 1 | "Hey guys", logo sting, scene-setting before payoff |
| **Hook type** | Identity-call ("if you own X..."), front-loaded payoff, or why/how question | Generic "Did you know...?", generic POV |
| **Frame 1** | High-contrast, in-focus, baked-in text overlay stating the value prop (acts as thumbnail) | Busy/ambiguous first frame, no overlay text |
| **Structure** | Myth-bust flip, question→math→reveal, or episodic Part 1/2 for dense topics | Meandering explainer with no single clear payoff |
| **Length** | 15-20s single insight; 45-90s only for real comparisons w/ a 20-30s re-hook; split dense topics into Part 1/2 | Artificially truncated video that cuts the real payoff to "keep it short" |
| **Pacing** | 135-160 wpm VO; pattern interrupt every 3-5s | Hyperactive edit (interrupt every 1s) or dead 5s+ stretches with zero change |
| **Captions** | Word-by-word karaoke-style, styled and timed | Static full-sentence blocks sitting unchanged for seconds |
| **Loop** | Last frame visually rhymes with first frame / a resolved sight-gag | No loop plan — video just ends |
| **Voice** | Non-default/cloned voice, emotion-tagged, Hormozi-style cadence for finance | Default top-10 TTS preset, flat monotone, cinematic trailer voice |
| **Music** | Consistent newsroom bed, ducked under VO, SFX sting on payoff beat | Same 1-second stock "breaking news" clip with zero variation forever; meme audio under serious takes |
| **CTA** | Exactly one, earned by content (save / follow-for-part-2 / genuine debate prompt) | "Comment WORD for DM", "Comment YES if you agree", stacked CTAs |
| **Production polish** | Native, lightweight, lo-fi-adjacent even when animated — trust over gloss | Heavy motion-graphic intros, corporate lower-thirds, ad-like polish |
| **Trend-chasing** | Original framing, ticker-specific, timely to actual news/earnings | Reposting a templatized format already circulating on "best hooks" listicles |

## Finance-compliance-safe framing (not-advice)

**Why this matters:** SEC's Dec-2025 risk alert names missing "point of dissemination" disclosure as the top finfluencer violation; FTC requires disclosures unavoidable, not buried; FINRA's first finfluencer enforcement action cost a broker-dealer $850,000.

| Rule | Application to our format |
|---|---|
| Disclose "educational only, not financial advice" **on-screen + spoken within the first ~30s** | For 15-20s videos: a persistent small lower-third disclaimer on any ticker-specific take; spoken line only needed if the video edges toward 30s+ |
| Never end-card-only disclosure | Caption must also restate it — don't rely on a single frame at the end |
| Favor concept education / myth-busting / comparisons over specific buy/sell/price-target calls | Performs comparably, saves better, far less regulatory exposure — default our scripts to "here's how the math works" not "here's what to buy" |
| Real-practitioner / plain-language framing over hype | Fits the deadpan anchor bit naturally — matter-of-fact explaining, not pumping |
| Re-issue hook + disclosure per platform on cross-post | Don't raw-repost the same cut across IG/TikTok/YT Shorts — recut opener, reconfirm disclosure each time |

**One-line disclaimer to bake into the template:** *"Educational only — not financial advice."* Place in lower-third overlay + caption text; add spoken version when the video runs a ticker-specific take past ~20s.

## Top 5 to lead with (highest leverage, lowest effort to implement now)

1. Cold open, payoff-first hook — zero lead-in, ever.
2. Word-by-word styled captions on every video, no exceptions.
3. One earned CTA, never engagement-bait phrasing.
4. Mirror first/last frame for loop — cheap to build into the modular flat-2D rig.
5. Persistent "not financial advice" lower-third on any ticker-specific video.

---

## Top 5 to actively avoid

1. Any "hey guys / welcome back" warm-up before the hook.
2. Default/top-10 stock TTS voice used unmodified.
3. Comment-to-unlock / "comment YES" engagement bait.
4. Heavy motion-graphic corporate intro before the sketch starts.
5. End-card-only compliance disclaimer with no on-screen/spoken version earlier.
